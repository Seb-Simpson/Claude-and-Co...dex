# Opening gameplay interface artwork

`ink-strip.svg` and `worn-rule.svg` are original, hand-authored vector artwork
created for NW-005B. No external imagery, generation service or additional font
license is required. They contain only decorative marks; all words are dynamic,
accessible DOM text.

The restrained ink strip and broken registration rule follow the NW-003B menu's
printed hospital identity. Typography reuses the existing OFL font packages:
Barlow Condensed, IBM Plex Mono and Cormorant Garamond. No menu asset is modified.

The SVGs contain no script, embedded text, external resource or GPU filter.
